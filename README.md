# JSON 拼接转换器与 JSON 可视化

两个页面都可以直接双击打开，使用 Chrome 或 Edge 即可，无需服务器、扩展或联网加载编辑器依赖。

## 日志转换

打开 `index.html`，粘贴 `Http result ... Json:` 日志，自动提取并修复跨行 JSON。有效结果可复制，也可点击“转换并跳转”，在新标签页中自动生成可视化。

转换页固定采用深蓝灰背景与青绿色强调色，与 JSON 可视化页的色系协调，不随系统主题切换。标题栏、输入区和输出区通过背景层次与边框区分；桌面并排显示输入与输出，宽度不超过 800px 时改为上下排列。按钮悬停、键盘焦点、禁用状态、文字选中和滚动条均适配深色外观，成功、警告、错误提示分别使用绿、黄、红色。

跳转时保留自动复制结果的行为。若浏览器阻止新窗口，请允许弹窗，或通过页面顶部“JSON 可视化”入口打开后手动粘贴。

## JSON 可视化

打开 `jsonviewer.html`。页面只有工具栏和一个深色编辑区，粘贴、格式化、压缩和继续修改都在同一区域完成。

- **校验**：输入后 500ms 自动校验；点击“校验”可立即检查。错误显示行列，点击提示定位。
- **可视化**：点击按钮或按 `Ctrl+Enter`，以四空格缩进格式化，显示不同类型的颜色与折叠按钮。不会在输入时自动重排内容。
- **行号**：左侧行号仅用于展示，不可选中；快速连续点击“收起/展开”时不会误选行号文本。正文仍可正常选择、编辑和复制。
- **压缩**：把当前内容压缩成一行。校验失败时，格式化和压缩都保留原文。
- **折叠**：使用行号旁放大的箭头或“全部展开 / 全部收起”，也可按 `Ctrl+Shift+[` 收起光标所在节点。收起节点时会同步折叠其所有层级的下级对象和数组；再次展开该节点只打开当前层，下级仍保持折叠，其他分支保持原有状态。收起后显示直接子项数量，例如 `{ … 3 项 }`、`[ … 5 项 ]`，重复属性分别计数。编辑触及隐藏内容时自动展开该节点，再次收起时更新计数。折叠只改变显示，复制的文档仍包含完整内容。
- **逐个展开**：每次展开文档中最靠前的收起节点，先父后子，并将光标和视口定位到该行；全部展开后按钮禁用。
- **复制 / 粘贴**：复制按钮复制完整文档；粘贴按钮在当前选择位置插入文本。也支持系统快捷键、选择复制、撤销和重做。剪贴板权限不足时可使用 `Ctrl+C / Ctrl+V`。
- **链接**：HTTP/HTTPS 字符串带下划线，`Ctrl+点击`（macOS 为 `Cmd+点击`）在新标签页打开；普通点击继续编辑。其他协议不会作为链接打开。
- **图片**：悬停网页链接 250ms 后尝试加载图片，加载成功才显示鼠标附近的预览；兼容没有图片扩展名的地址。鼠标移开或编辑、折叠时隐藏预览。
- **颜色**：悬停颜色字符串 value（含两侧引号）250ms 后，在鼠标附近显示约 180 × 110px 的矩形色块，透明色使用棋盘格底纹。支持 `#RGB`、`#RGBA`、`#RRGGBB`、RGB/RGBA、HSL/HSLA、标准 CSS 颜色名及 `transparent`；8 位十六进制统一按 Android `#AARRGGBB` 解释，例如 `#80FF0000` 为半透明红色，4 位 `#RGBA` 的透明度仍在末位。支持对象属性值、数组元素和顶层字符串，识别 JSON 转义后的颜色，原文保持不变；键名、十进制整数、无效颜色及 `var()`、`currentColor` 等依赖页面上下文的表达式不显示。只在悬停时预览，不添加常驻小色块或左侧栏。预览跟随鼠标并避让屏幕边缘；移开鼠标、编辑、折叠、滚动、窗口缩放或失焦时隐藏，与图片、时间戳预览互斥。
- **时间戳**：悬停 10 位秒级或 13 位毫秒级正整数 250ms 后，显示北京时间（`Asia/Shanghai`），例如 `2026/10/30 16:55:34`。支持对象属性值、数组元素和顶层数值；数字字符串、小数、负数和科学计数法不显示。符合位数的数字 ID 也可能出现提示，原文保持不变。
- **统计**：工具栏显示行数、字符数、当前文本的 UTF-8 文件大小和 JSON 深度。大小包含排版空白及折叠内容，按 1024 换算为 KB/MB，悬停可查看准确字节数；不是磁盘上的文件大小。根对象/数组深度为 1，嵌套容器逐层加 1，顶层基本类型为 0；空文本或错误 JSON 显示 `—`。输入后与自动校验同步更新，修改期间显示“更新中”。

键名及其双引号为青色，普通字符串及其双引号为绿色；链接正文为蓝色下划线，两侧双引号为绿色。花括号为白色，方括号为浅黄色。编辑区使用四空格缩进、13px 字号（窄屏 12px）和紧凑行距。格式化和压缩保留原始数字字面量、属性顺序、重复属性及字符串转义，不会把长整数 ID 转为浮点数。支持对象、数组和顶层基本类型。长行可横向滚动。

## 数据处理

JSON 仅在本地页面内存中处理，刷新或关闭后清空，不写入 URL、磁盘存储或新增服务。转换器和可视化页通过校验窗口来源与一次性标识的消息传递结果，接收后清理标识。图片预览会在悬停时请求链接原地址。

旧版外站自动化扩展已退役；新流程不需要安装或启用扩展。

## 开发

`jsonviewer.js` 为随项目分发的本地打包文件。用户直接打开 HTML 即可。修改编辑器源代码后，在项目目录执行：

```sh
npm ci
npm test
npm run build
```

编辑器源代码位于 `src/`，构建脚本位于 `scripts/`。构建会同步生成 `THIRD_PARTY_NOTICES.txt`，分发时保留该文件。运行时不使用 CDN。
