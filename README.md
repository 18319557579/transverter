# JSON 拼接转换器

本地静态网页，用于从 `Http result ... Json:` 日志中提取并修复跨行 JSON。网页可直接打开，不会将原始日志上传到新增服务。

## 打开网页

直接打开项目根目录中的 `index.html`。

## 启用“转换并跳转”自动化

由于浏览器的同源安全限制，本地网页不能直接操作 ESJSON 页面。项目中的 Manifest V3 扩展负责在两个页面间传递一次性数据并完成自动操作。

Chrome 和 Edge 的安装步骤相同：

1. 打开浏览器扩展管理页：Chrome 使用 `chrome://extensions`，Edge 使用 `edge://extensions`；
2. 开启“开发者模式”；
3. 点击“加载已解压的扩展”，选择项目中的 `browser-extension` 目录；
4. 打开该扩展的“详细信息”，启用“允许访问文件网址”；
5. 重新打开或刷新 `index.html`。

安装后，在有效 JSON 结果下点击“转换并跳转”，扩展会打开 ESJSON、填入转换结果并自动点击“可视化”。

## 降级行为

扩展未安装或未允许访问文件网址时，按钮仍会复制转换结果并打开 ESJSON。此时需要手动粘贴并点击“可视化”。

## 数据处理

- JSON 不写入跳转 URL，URL 中只有一次性随机令牌；
- 数据只保存在扩展的浏览器会话存储中；
- 自动操作完成或目标标签页关闭后，临时数据会被删除；
- 单次自动传递上限为 8 MB，超过限制时可使用“复制结果”。
